### 1. 🔑 Рабочее место Администратора (`ADMIN`)

### 2. 🏢 Личный кабинет Организатора (`ORGANIZER`)

  - [x] Принятие заявки (`VolonteerEventRequest` → `ACCEPTED`)

- [x] Подтверждение отработанных часов по итогам события (`VolonteerEventRequest` → `CONFIRMED`)

## 🔄 Реализация жизненных циклов (State Machine)

### Событие (`Event`)
```
[Создание] ──► CREATED ──(Админ: Одобрить)────► ACCEPTED ──(Организатор: Закрыть)──► CLOSED
                  │                                  ▲
                  └──(Админ: Отклонить)──► CANCELLED ─┘
```

### Заявка волонтера (`VolonteerEventRequest`)
```
[Подача] ──► PENDING ──(Орг: Одобрить)────► ACCEPTED ──(Орг: Подтвердить часы)──► CONFIRMED
                │
                └──(Орг: Отклонить)──► CANCELLED
```

## 🛠 Архитектура и стек решений

- **Frontend:** HTML5, CSS3 (Modern Design System, CSS Custom Properties, CSS Grid/Flexbox), Vanilla JS (ES Modules / SPA Architecture without heavy build bloat for instant preview).
- **Хранилище состояния:** LocalStorage с предварительно загруженными демо-данными (готов к сбросу/перезагрузке в один клик).
- **Backend-интерфейс:** Слой абстракции `GraphQL Client` (`graphql-schema.graphql` и `api/client.js`), совместимый со спецификацией **DataSpace Community Edition**.
- **Макет и адаптивность:** Полная поддержка Desktop и мобильных экранов, переключатель ролей "на лету" без необходимости перелогиниваться.

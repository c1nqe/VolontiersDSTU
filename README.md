## 📋 Описание проекта

**VolontiersDSTU** — frontend-приложение для учёта и управления волонтёрской деятельностью, разработанное в рамках хакатона «ВЕСНА '25». Система позволяет администраторам, волонтёрам и организаторам событий взаимодействовать через единую платформу: регистрация, подача заявок на участие в событиях, согласование, подтверждение фактов работы и получение выписок по отработанным часам.

---

## 🎯 Цели и задачи

- Разработка полноценного frontend-приложения промышленного уровня
- Реализация трёх рабочих мест: **Администратор**, **Волонтёр**, **Организатор**
- Интеграция с backend на базе **DataSpace Community Edition** (GraphQL)
- Управление жизненным циклом событий и заявок волонтёров

---

## 👥 Роли пользователей

### 🔑 Администратор
| Функция | Описание |
|---------|----------|
| Регистрация организаторов | Создание аккаунтов организаций (`Organization`) |
| Регистрация волонтёров | Создание аккаунтов волонтёров (`Volonteer`) |
| Модерация событий | Согласование или отмена событий (`Event` → `ACCEPTED` / `CANCELLED`) |

### 🏢 Организатор (создатель событий)
| Функция | Описание |
|---------|----------|
| Создание событий | Подача заявки на новое событие (`Event`) |
| Управление заявками | Согласование/отмена заявок волонтёров (`VolonteerEventRequest` → `ACCEPTED` / `CANCELLED`) |
| Подтверждение работы | Подтверждение факта работы волонтёра (`VolonteerEventRequest` → `CONFIRMED`) |
| Закрытие событий | Завершение события (`Event` → `CLOSED`) |

### 🙋 Волонтёр
| Функция | Описание |
|---------|----------|
| Просмотр событий | Просмотр доступных событий (`Event` со статусом `ACCEPTED`) |
| Подача заявок | Подача заявки на участие в событии (`VolonteerEventRequest`) |
| Выписка по часам | Получение выписки об отработанных часах за период (`VolonteerEventRequest` → `CONFIRMED`) |

---

## 🔄 Жизненный цикл сущностей

### Событие (Event)
```
CREATED → ACCEPTED / CANCELLED → CLOSED
```
1. Организатор создаёт событие → статус `CREATED`
2. Администратор согласовывает → статус `ACCEPTED` или отменяет → `CANCELLED`
3. Организатор закрывает после проведения → статус `CLOSED`

### Заявка волонтёра (VolonteerEventRequest)
```
PENDING → ACCEPTED / CANCELLED → CONFIRMED
```
1. Волонтёр подаёт заявку → статус `PENDING`
2. Организатор согласовывает → `ACCEPTED` или отменяет → `CANCELLED`
3. Организатор подтверждает факт работы → `CONFIRMED`
